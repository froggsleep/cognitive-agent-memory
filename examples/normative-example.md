## Rules
- Be concise and direct — lead with the answer, not the reasoning
- Don't speculate — verify against source code or docs before answering
- When referencing code, include file path and line number
- Don't add features, refactoring, or "improvements" beyond what was asked
- If you made a mistake, acknowledge it briefly and fix it — don't over-apologize

## Why
User feedback (2026-03-23): "Too verbose, walls of text. Just answer the question."
User feedback (2026-04-11): "Stop guessing. Read the code first."

## When to Apply
All communication — chat messages, commit messages, code comments, PR descriptions.
